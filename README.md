# 115tools

基于 115 网盘的 Emby 媒体库同步工具（v2 全新重写）：以**任务中心**为核心，支持任意数量的同步任务（本地 → 云端 / 云端 → 本地），每个任务绑定一对目录并携带独立的行为开关。

> **免责声明**：本项目由 AI 编程助手编写生成。请在使用前自行评估风险，部署与使用产生的一切后果由使用者自行承担。

## 功能

- **任务中心** — 卡片式管理多个同步任务，每个任务独立配置本地目录、云端目录与一整套选项
- **本地同步（push）** — 文件事件监听 + 定时全量扫描，自动上传新增/修改文件到云端；视频上传后本地替换为 `.strm` 直链
- **云端同步（pull）** — 云端新文件落地到本地（视频写 `.strm` / 普通下载）、冗余文件删除、可选移入回收目录
- **离线下载** — 添加 http/magnet/ed2k 链接或上传种子文件，直接下载到 115 网盘指定目录
- **透传本地缓存** — 上传完成的视频按 pickcode 暂存本地，Emby 通过 `/download` 直链播放时命中本地可跳过 115 上游回源
- **执行历史** — 每次执行（手动/定时/监听/启动）留结构化记录与明细日志，任务卡片「日志」按钮可回看

## 使用说明

### 必填全局设置

启动后在「设置」页填写以下 **4 项必填**，缺一项同步不会启动（缺失项在任务中心顶部横幅提示，补全保存后自动开始）：

| 配置项 | 用途 | 示例 |
|--------|------|------|
| `refresh_token` | 115 开放平台刷新令牌，换取访问令牌 | — |
| `strm_url` | STRM 链接前缀（`/download` 直链地址） | `http://设备IP:端口号` |
| `temp_dir` | 云端回收目录（清理视频时移入，可找回） | `/Temp` |
| `cache_dir` | 本地透传缓存目录（上传视频暂存，命中直读） | `/mnt/cache` |

### 任务中心

全局设置保存后，在「任务中心」新建任务。任务分两类：

- **本地同步（push）**：本地 → 云端。绑定一对「本地目录 ↔ 云端目录」。
  - 文件事件监听 + 监听静默时间（分钟）
  - `.strm` / 视频文件立即同步（绕过静默窗口）
  - 定时全量扫描（开关 + 间隔小时）+ 全量后是否扫描云端
  - 生成 STRM（视频上传后本地替换 `.strm`；关 = 保留原视频，纯云端备份）
  - 上传后移入 cache 目录（关 = 删除原视频）
- **云端同步（pull）**：云端 → 本地。绑定一对目录。
  - 定时同步（开关 + 间隔小时）
  - 生成 STRM（关 = 下载原视频）
  - 下载云端存在本地不存在的文件
  - 冗余文件删除
  - 同步后移动到 temp 目录（等价旧「STRM 生成」的收尾动作）

每个任务卡片提供：执行 / 停止、日志（执行历史 + 明细日志）、编辑、删除（可勾选同时清理索引）。

### 日常操作约束

同步以「本地文件为准」：本地由监听 + 全量扫描自动上传 / 清理云端；云端只用来「放新文件进来」。

- **云端侧**：只允许「新增」；禁止对已有文件删除、移动、重命名、覆盖。
- **本地侧**：可新增 / 删除 / 移动 / 重命名，程序自动同步到云端。

一句话：**想动云端的东西，先在本地对应位置操作，再让程序同步上去。**

### 透传本地缓存

视频上传完成后，按 pickcode 分目录移入 `cache_dir`（`<cache_dir>/<pickcode>/<原名>`）。Emby 通过 `/download` 直链播放（透传模式，空 UA 或 `Lavf/*`）时命中本地即跳过 115 上游回源。

> `cache_dir` 建议与任务本地目录同挂载点（移入走原子 rename），跨设备自动退化为拷贝。缓存保留期由「缓存保留天数」控制（默认 1 天，到期自动清理）。

## 部署

```yaml
services:
  115tools:
    image: ghcr.io/ytx-zhang/115tools:latest
    container_name: 115tools
    environment:
      - TZ=Asia/Shanghai
      - LOG_LEVEL=INFO            # DEBUG / INFO / WARN / ERROR；DEBUG 时任务日志也会记录调试明细
    volumes:
      - ./config/:/app/data          # 数据目录（config.json / index.db / journal.db）
      - /path/to/media:/media        # 本地媒体目录（在任务里填 /media 这类容器内路径）
    ports:
      - "8080:8080"
    restart: unless-stopped
```

启动后访问 `http://your-server:8080`：

1. Web 面板先于同步启动，即使配置不完整也能打开
2. 「设置」页填齐 4 项全局必填后，同步引擎自动启动
3. 「任务中心」新建任务，绑定本地目录（容器内路径）与云端目录（115 绝对路径）

### 数据文件

| 文件 | 用途 |
|------|------|
| `<数据目录>/config.json` | 全局设置 + 任务集合（程序自动维护，无需手填） |
| `<数据目录>/index.db` | 本地路径 ↔ 云端 FID 索引 |
| `<数据目录>/journal.db` | 执行历史 + 明细日志 |
